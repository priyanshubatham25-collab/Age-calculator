# 🎂 Age Calculator

A web application that calculates a user's age from their date of birth and the current date.

## 🚀 Features

- Enter date of birth
- Calculate age in years, months, and days (if implemented)
- Display the calculated result
- Simple and user-friendly interface
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💡 How It Works

1. Enter your date of birth.
2. Click the Calculate button.
3. View your calculated age.

No backend server is required if the project uses only HTML, CSS, and JavaScript.
